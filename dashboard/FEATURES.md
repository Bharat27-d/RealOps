## 1. Event Management

### Scenario Pack System
**Purpose**: Send multiple event scenarios to users/channels in one grouped message

**Features**:
- Create unlimited scenarios in one session
- Customize global header (title, description, color, logo)
- Per-scenario customization:
  - Custom title (or auto-numbered)
  - Description (required)
  - Image URL
  - Custom color
- Drag-and-drop reordering
- Live preview of final message
- Optional user mention
- Select specific channel for delivery

**Use Case**: Event planning team sends 4-6 scenarios to event organizer for review

**How to Use**:
1. Navigate to Events page
2. Click "Create Scenario Pack"
3. Configure header settings
4. Add scenarios (minimum 1, recommended 4-6)
5. Reorder with arrow buttons if needed
6. Select destination channel
7. Add user ID to mention (optional)
8. Click "Send Scenarios"

### Event Announcements
- Create event announcements with title, description, date, time
- Add event images
- Schedule for future posting
- Visual timeline view (coming soon)

### Event Forums
- Auto-create event-specific forums
- Auto-lock after event completion
- Auto-archive old events

## 9. Advanced Embed Builder

### Full Customization
**Features**:
- **Basic Settings**:
  - Title (up to 256 characters)
  - Description (up to 4096 characters)
  - Color (hex color picker)
  - Timestamp toggle

- **Media**:
  - Thumbnail URL
  - Main image URL
  - Image preview in editor

- **Author**:
  - Author name
  - Author icon URL

- **Footer**:
  - Footer text (up to 2048 characters)
  - Footer icon URL

- **Fields** (up to 25):
  - Field name (up to 256 characters)
  - Field value (up to 1024 characters)
  - Inline option
  - Drag to reorder

- **Interactive Elements** (coming soon):
  - Buttons
  - Select menus

### Template System
- Save embeds as templates
- Load saved templates
- Duplicate existing embeds
- JSON import/export for advanced users

### Live Preview
- Real-time preview as you edit
- See exactly how it will look in Discord
- Character count tracking (6000 max)
- Warning when approaching limits

### Send Options
- Send immediately to any channel
- Save without sending
- Send and save as template

**Use Case**: Marketing team creates announcements, events team builds event notifications
