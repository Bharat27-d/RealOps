# RealOps

A comprehensive Discord Bot and Full-Stack Management Dashboard built to streamline server operations, event management, and community engagement.

![RealOps Dashboard Preview](https://i.ibb.co/FMYFdhk/real-ops-group-logo.png)

## 🌟 Overview

The RealOps project is an all-in-one community management solution tailored for the RealOps Group. It combines a powerful Discord bot for member interactions with a modern web dashboard for staff and administrators to manage operations efficiently.

## ✨ Core Features

### 🤖 Discord Bot Capabilities
- **Advanced Ticket System**: Multi-department support tickets with automatic HTML transcript generation and cloud archiving.
- **Event & Scenario Management**: Built-in tools for scheduling, managing, and tracking community events and scenario packs.
- **Dynamic Custom Commands**: A flexible system allowing staff to create, edit, and deploy bot commands on the fly.
- **Role Management**: Automated role assignments, reaction roles, and nickname rule enforcement.
- **Staff Operations**: Integrated tools to manage staff applications, track availability, and handle team scheduling.

### 📊 Management Dashboard
- **Modern Web Interface**: A sleek, responsive, dark-themed management portal built with React.
- **Rich Visual Analytics**: Real-time data tracking for ticket resolution rates, event completion, and staff engagement.
- **Interactive Embed Builder**: Design, preview, and send rich Discord embeds directly from your browser.
- **Real-Time Control Panel**: Deploy interactive Discord panels, toggle features, and update bot configurations instantly without requiring reboots.

## 🛠️ Technology Stack

- **Bot Engine**: Node.js & Discord.js v14
- **Frontend Web App**: React.js, React Router, Recharts
- **Backend API**: Node.js, Express.js
- **Database Architecture**: Hybrid Local Cache + Firebase Firestore integration for high-performance persistence.
